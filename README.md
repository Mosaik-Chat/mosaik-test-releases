# Mosaik

Mosaik is a free AI chat app for Windows 10 and 11.

This repository holds Mosaik's installers and is where you can report bugs and talk about Mosaik.
Mosaik's code is not open source and isn't kept here.

- **Download:** [mosaikchat.com/download](https://mosaikchat.com/download), or the newest
  installer under [Releases](https://github.com/Mosaik-Chat/mosaik/releases/latest)
- **What's new:** [mosaikchat.com/releases](https://mosaikchat.com/releases)
- **Help:** [mosaikchat.com/docs](https://mosaikchat.com/docs)
- **Found a bug?** Choose *Report a problem* in Mosaik (Ctrl P), or open an [issue](https://github.com/Mosaik-Chat/mosaik/issues)
- **Questions and ideas:** [Discussions](https://github.com/Mosaik-Chat/mosaik/discussions)
- **Privacy:** [mosaikchat.com/privacy](https://mosaikchat.com/privacy)
