# Mosaik test releases

Test builds of Mosaik, the free AI chat app for Windows 10 and 11. Each release here is a build
made for trying a change before it reaches everyone, tagged `v<version>-test.<run>`. These builds
may have problems the public release does not.

Mosaik's code is not open source and isn't kept here.

- **The public release:** [mosaikchat.com/download](https://mosaikchat.com/download), or
  [Releases](https://github.com/Mosaik-Chat/mosaik/releases/latest) in the public repository
- **Found a bug in a test build?** Choose *Report a problem* in Mosaik (Ctrl P) and name the test
  build's version
- **Help:** [mosaikchat.com/docs](https://mosaikchat.com/docs)
- **Privacy:** [mosaikchat.com/privacy](https://mosaikchat.com/privacy)
